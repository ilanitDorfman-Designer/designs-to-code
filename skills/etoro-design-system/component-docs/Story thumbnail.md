 **Purpose**

 Story Thumbnails provide a visual entry point to ephemeral content (stories). They indicate availability and viewing status while enabling quick access to the story viewer.  **When to use**

-  Representing story content in a compact, circular format

-  Indicating new vs viewed content

-  Providing quick access to sequential story experiences

-  Displaying user or content-driven story previews

 

 **Variants **

-  **Unviewed** Indicates new or unseen content. Uses a highlighted primary ring. 

-  **Viewed** Indicates content that has already been seen. Uses a neutral or muted ring. 

-  **With Label** Includes a username or title below the thumbnail. 

-  **With Indicator (Optional)** May include a small badge or indicator (e.g. Live, New). 

 **Usage Guidelines**

 

 **Do**

-  Use Story Thumbnails only for ephemeral content entry points

-  Clearly distinguish between viewed and unviewed states

-  Keep the circular shape consistent

-  Use labels when multiple thumbnails are displayed

-  Maintain consistent size and spacing

-  Group in horizontal, scrollable layouts

 

 **Avoid**

-  Using Story Thumbnails for navigation or static content

-  Using them as generic avatars without story functionality

-  Removing or weakening the viewed/unviewed distinction

-  Adding multiple competing indicators

-  Using low-contrast or unclear status rings

 

 **States & Behavior**

-  Resting (viewed / unviewed)

-  Hover

-  Active (pressed)

-  Focus

-  Disabled (optional)

-  Entire thumbnail is clickable

-  Click opens the associated story

-  Viewed state updates after the story is consumed

-  Status ring reflects current viewing state

-  Component remains visually consistent regardless of content inside

-  Fully accessible via keyboard and screen readers
