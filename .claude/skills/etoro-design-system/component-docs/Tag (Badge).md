-  **Purpose ** Tags highlight **key attributes** or distinctions related to an item. They provide visual emphasis for short, descriptive information without enabling user interaction.  **When to use**

-  Highlighting attributes (e.g. Winner, Popular, Top Performer)

-  Providing categorical or contextual emphasis

-  Displaying short labels within dense layouts, such as tables or lists

-  Representing qualitative distinctions (e.g. Positive / Negative)

-  Comparing categories using consistent accent colors

-

-  **Overflow indicator **When space is limited, a +# or ellipsis can be used to indicate additional hidden tags.  **Usage Guidelines  Do**

-  Keep labels short and meaningful (1–2 words)

-  Use Carbon tags in dense environments to avoid visual overload

-  Use Verdict tags only when meaning is clearly positive or negative

-  Use Category accents consistently for the same entities

-  Place tags close to the content they describe

-  Use tags freely inside table cells where quick scanning is required

-  Use tooltip on overflow (+# / ellipsis) to reveal the full list

-  

-  **Avoid**

-  Using tags as actions or navigation

-  Making tags clickable or hover-reactive

-  Using Verdict styling for neutral categorization

-  Reassigning Category accent colors inconsistently

-  Using tags to communicate complex states or long text

-  Overusing accent colors without a defined semantic system

-  

-  **States & Behavior**

-  Default state only (non-interactive)

-  No hover, active, or focus states

-  Tooltip appears only when an overflow indicator is present

-  Tooltip reveals full tag content and is keyboard accessible

-  Tag content must remain legible at both supported sizes (M and S)

-  Color usage must meet accessibility contrast requirements
