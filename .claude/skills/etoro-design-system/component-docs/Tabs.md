 **Purpose**

 Tabs organize related content into separate views within the same context. They allow users to switch between sections without navigating away from the current page.

 

 Tabs preserve layout structure while changing the displayed content 

 **When to use**

-  Switching between related content sections

-  Organizing peer-level information within the same hierarchy

-  Separating structured content areas inside dashboards or detail pages

-  Navigating between logical content groupings within a container

 

 **Variants**

-  **Default Tabs** Horizontal tabs with text labels.

-  **With Icon** Tabs may include an icon when it improves recognition

-  **Scrollable Tabs** Used when the number of tabs exceeds available horizontal space

-  **Disabled Tab** Used when a section is unavailable

 

 **Usage Guidelines**

 **Do**

-  Use tabs for peer-level content sections

-  Keep labels short and descriptive

-  Maintain consistent order across similar pages

-  Ensure selected tab is clearly distinguishable

-  Use tabs when the content beneath them changes significantly

-  Support keyboard navigation for accessibility

 

 **Avoid**

-  Using tabs for filtering data sets (use Filter Chips)

-  Using tabs for switching small display modes (use Toggle Group)

-  Using tabs for binary choices (use Toggle Group)

-  Using tabs for multi-select behavior (use Filter Chips)

-  Overloading tabs with too many options (consider restructuring content)

-  Mixing tabs with unrelated navigation patterns in the same row

 

 **States & Behavior**

-  One tab is always selected

-  Selection updates content immediately

-  No confirmation required

-  Each tab supports: Resting, Hover, Active (pressed), Focus, and Disabled

-  Selected tab is visually distinct using neutral emphasis styling

-  Only one tab can be active at a time

-  Arrow keys move focus between tabs

-  Screen readers announce selected state and position

-  Tabs do not create new surfaces

-  Tab content replaces the content area beneath the tab bar
