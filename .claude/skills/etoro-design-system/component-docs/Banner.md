 Purpose

 Banners communicate **persistent, contextual messages** within a page. They are primarily used for platform announcements, promotions, or feature highlights that require visibility but do not interrupt user flow.

 

 When to use

-  Promoting features or campaigns

-  Highlighting relevant opportunities (e.g., new feature available)

-  Communicating platform-wide announcements

-  Encouraging optional user actions

-  Providing contextual marketing messaging

 

 Variants  **Informational Banner **Used for neutral platform messaging or feature communication  **Promotional Banner **Used for marketing-oriented messaging with optional illustration or stronger visual emphasis.  **With Illustration **Includes an image or visual to increase engagement or draw attention. Typically used in marketing or campaign contexts..  **With Action(s) **Includes one primary CTA and optionally one secondary action...  Usage Guidelines  Do

-  Use banners for persistent, non-blocking communication

-  Keep messaging concise and benefit-focused

-  Include a clear primary CTA when action is desired

-  Ensure banners feel integrated within the layout

-  Use illustration only when it supports the message

-  Limit to one banner per section or page area

 

 Avoid

-  Using banners for validation, error, or transactional feedback (use Toast)

-  Blocking user flow (use Modal if interruption is required)

-  Stacking multiple promotional banners

-  Using overly strong visual treatment that competes with primary page content

-  Placing banners mid-flow without contextual relevance

 

 States & Behavior

-  Banners are persistent within their container

-  They do not auto-dismiss

-  They do not block interaction

-  They live within the parent surface (no elevation above layout unless intentionally defined)

-  If dismissible, dismissal should persist during the session (or longer if defined)

-  CTA buttons follow standard button hierarchy rules

-  Illustration is decorative and should not carry critical information
